# Chat Frontend

Standalone chat frontend copied from the ticketing frontend chat system.

## Backend

The app is configured to use the existing backend API:

```env
VITE_API_URL=http://localhost:4701
```

Backend source path referenced by the parent project:

```text
C:\Users\Techn\ticketing_backend\src
```

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:5174/chat-app`.
